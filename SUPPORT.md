# Support

Thanks for using WAVE. Here's the fastest way to get help.

## Questions and help

- **Docs** — start at [wave.online](https://wave.online) and the product subdomain (e.g. `dispatch.wave.online`).
- **API and SDKs** — see the [`api-spec`](https://github.com/wave-av/api-spec) and the SDK repos.
- **Discussions / questions** — open a [GitHub Discussion](https://github.com/orgs/wave-av/discussions) or email [support@wave.online](mailto:support@wave.online).

## Bugs and feature requests

Open an issue in the relevant repository using the issue templates. Include what you expected, what happened, and the steps to reproduce.

## Security

Please **do not** open public issues for vulnerabilities — follow the [Security Policy](./SECURITY.md) and email [security@wave.online](mailto:security@wave.online).

## Enterprise

For SLAs, procurement, or partnership, contact [enterprise@wave.online](mailto:enterprise@wave.online).
